# 🐢 Marcelo | Dev Portfolio (TMNT Edition)

Portfólio web responsivo e estilizado com o tema das Tartarugas Ninja, desenvolvido para o módulo de Front-End da **EBAC** com HTML5, CSS3 moderno e JavaScript.

---

## 📌 Destaques & Estrutura do Projeto

- **Arquitetura Modular:** Separação limpa de responsabilidades em arquivos externos (`index.html`, `style.css` e `script.js`).
- **Design Temático TMNT:** Interface escura estilizada com detalhes visuais e paleta inspirada no universo das Tartarugas Ninja.
- **Interatividade em JavaScript:** Botão interativo que alterna o estado de exibição de elementos e notificações via manipuladores de eventos (`addEventListener`) e estruturas condicionais (`if/else`).
- **Navegação & Seções:**
  - **Sobre Mim:** Apresentação profissional, tags de interesses pessoais e resumo de competências.
  - **Experiência & Formação:** *Timeline* detalhando atuação em Suporte/Cloud de TI e formação acadêmica.
  - **Projetos & Laboratórios:** Grid responsivo com *badges* de status dos projetos atipicamente desenvolvidos.
- **Atalhos Interativos no Rodapé:**
  - **Leonardo:** Link direto para o perfil no GitHub.
  - **Donatello:** Link direto para o perfil no Spotify.
  - **GIF do Mikey:** Animação temática integrada à interface.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estruturação semântica)
- **CSS3** (Flexbox, CSS Grid, variáveis e responsividade)
- **JavaScript (ES6+)** (Manipulação de DOM e lógica condicional)
- **Git & GitHub** (Controle de versão)
